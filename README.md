# Vitapio ECG demo

Live 8-lead ECG over Bluetooth Low Energy, drawn in the browser with Web Bluetooth
(Chrome on Android). The device side is a NUCLEO-F401RE generating a synthetic ECG
and an ESP32-C3 acting as the BLE modem.

- Page: https://mertart.github.io/vitapio-ecg-demo/
- Without a device: https://mertart.github.io/vitapio-ecg-demo/?sim=1
